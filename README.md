# 龍蝦AI個人檔案產生器 (OpenClaw Lobster Profile Generator)

為你的 OpenClaw 龍蝦打造獨一無二的個性與專屬 AI 代理特工身分證！

---

## 🌟 核心特色

1. **視覺與頁面設計規範**：
   - **標題**：龍蝦AI個人檔案產生器
   - **副標題**：為你的OpenClaw龍蝦打造獨一無二的個性
   - **配色**：深藍色漸層背景（`#1a1a2e` → `#16213e`）、清晰白色文字、醒目橘紅色（`#e94560`）光暈按鈕
   - **風格**：現代簡潔賽博風格、圓角卡片（Border-radius 16~24px）、層次感毛玻璃（Glassmorphism）與高質感發光陰影

2. **三大圖片規範核心功能（IDENTITY.md 規範）**：
   - 🏷️ **1. 龍蝦名字**：文字輸入框，預設值為 `小龍`，支援一鍵隨機命名
   - 🗣️ **2. 說話風格**：下拉選單（溫柔體貼 / 幽默風趣 / 專業嚴謹 / 活潑可愛）
   - 🌐 **3. 主要語言**：下拉選單（繁體中文 / 英文 / 日文）
   - 📝 **4. 個性描述**：多行文字框（textarea），附 placeholder 與精選個性範本切換
   - 💼 **5. 擅長領域**：多選框（生活助手 / 程式開發 / 教育教學 / 創意寫作 / 資料分析）
   - 📏 **6. 回覆長度偏好**：單選按鈕（簡短精要 / 中等長度 / 詳細完整）
   - ⚡ **「產生個人檔案」按鈕**：點擊後根據表單內容即時生成標準 `IDENTITY.md` Markdown 格式文字
   - 💻 **深色程式碼區塊**：高對比終端風格預覽區，完美排版呈現 `# IDENTITY.md`、`## 基本資訊`、`## 個性與風格`、`## 擅長領域`、`## 行為規範`
   - 📋 **「複製到剪貼簿」按鈕**：一鍵將內容複製至系統剪貼簿，複製成功後按鈕文字變為「`✅ 已複製！`」持續兩秒後自動恢復

3. **四大甲殼武裝外觀（高解析特工立繪）**：
   - ⚡ **霓虹賽博發光螯**（Cyberpunk Neon）
   - 👑 **帝王黃金熔岩甲**（Emperor Golden）
   - 🌌 **深淵生物藍晶螯**（Abyssal Bioluminescent Blue）
   - 🦞 **波士頓真紅重裝**（Crimson Boston Mecha）

4. **深度個性與能力配置 Studio**：
   - **基本識別**：代號名稱、軍階稱號、主要語言與說話風格
   - **雙螯專屬武裝**：雙持超導量子光子鉗、超重型液壓粉碎大螯、青軸機械連打爪、深海珍珠力場護盾、反重力魚雷推進器
   - **五維屬性雷達**：夾碎Bug力、賽博耐鹽度、神經脈衝頻率、隱匿摸魚度、幸運脫殼率（附帶快速預設方案）
   - **語錄與口癖**：戰鬥座右銘自訂/隨機、說話口癖結尾詞（`~夾！`、`咔嚓！`、`🤖嗶嗶` 等）

5. **即時互動認證卡與匯出功能**：
   - 🪪 **動態全息特工身分證**：即時換裝、五維能力條、即時個人檔案、戰力評分（CP）與稀有度徽章（SSR / UR / EX）
   - 📄 **一鍵下載 `IDENTITY.md` 檔案**：直接匯出標準特工 Markdown 規範檔案
   - 🖼️ **高畫質特工卡圖片下載 (PNG)**：基於 HTML5 Canvas 即時繪製並下載精美個人檔案卡
   - 📋 **一鍵複製 OpenClaw System Prompt**：可直接貼給 Claude / ChatGPT 作為系統提示詞
   - 📦 **一鍵複製 Agent JSON**：標準化 OpenClaw Agent Specification
   - 🔊 **Web Audio 賽博音效合成**：雙鉗夾擊聲、量子充能聲與靜音切換
